# Escrever ADR

- Contexto: o problema e as forças em jogo, sem a solução.
- Decisão: uma frase no imperativo e os detalhes que a tornam testável.
- Alternativas consideradas, com o motivo de cada descarte. Se o design doc não registra alternativas, diga isso.
- Consequências boas e ruins. Próximo número livre; status Proposto até o autor aceitar.
